# SlabPlan Security

## Reporting a vulnerability

Report suspected SlabPlan vulnerabilities to `sales@tarobuild.com` with the
subject **SlabPlan security report**. Include the affected URL or component,
impact, reproduction steps, and any safe supporting evidence.

Do not include customer records, credentials, access tokens, private files, or
other secrets in the initial report. Do not disrupt the service, access another
company's workspace, or retain data that does not belong to you.

We will triage reports, preserve relevant evidence, investigate the affected
boundary, and coordinate remediation and communication appropriate to the
severity of the issue.

## Supported version

Security fixes are applied to the current production version of SlabPlan at
`https://www.slabplan.com`. Preview builds and old local revisions are not
separately supported.

## Compliance language

SlabPlan uses Replit and Supabase services that maintain SOC 2 Type II
attestations. Their attestations do not transfer to Taro Build or SlabPlan.
SlabPlan does not currently claim an independent SOC 2 report.
