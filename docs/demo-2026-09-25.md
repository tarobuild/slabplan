## Maintainer Notes

`scripts/demo/refresh_demo.mjs` is an explicit, TEST-only API utility, not an
application startup seed. It requires the authorized HTTPS origin and private
local account/state files. Reads verify account roles, saved identities, shared
organization, and TEST job names before mutations; writes require `--execute`.

The September PDF generator uses ReportLab from the document-tooling runtime.
It does not add any dependency to the web application. It expects the labeled
generated image in `output/demo-september/assets`.

Run content, upload, invoice, schedule, and verification steps separately when
resuming. Do not rerun financial-content refresh after importing the invoice,
because that refresh deliberately resets the demo's progress percentages.

The custom-phase fix adds the owning organization at creation, validates it
at assignment, and backfills only NULL organization keys from owning jobs.
It does not reassign phases that already have an organization.
